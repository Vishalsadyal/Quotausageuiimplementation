CHROME WEB STORE PRIVACY FORM — AutoApply CV LinkedIn Copilot
=============================================================

SINGLE PURPOSE DESCRIPTION
--------------------------
Helps users apply to LinkedIn Easy Apply jobs by providing a guided copilot panel that assists with filling and submitting applications, and syncs application activity to the user's own AutoApply CV dashboard.

PERMISSION JUSTIFICATIONS
-------------------------
storage:
Stores the extension's settings and application state locally so user preferences persist between sessions.

tabs:
Used to find, open and activate the user's LinkedIn job tabs so the copilot runs on the correct page and can send status updates to the popup.

scripting:
Used to inject the copilot panel and form-filling helpers into the LinkedIn jobs page the user is viewing.

activeTab:
Provides temporary access to the active tab so the user can run the copilot on a job page without requesting broad site access.

alarms:
Used for background scheduled checks so application status stays up to date without user action.

HOST PERMISSION JUSTIFICATION
-----------------------------
Needed to run the copilot on LinkedIn jobs pages (https://www.linkedin.com/jobs/*) and to sync application activity with the user's own dashboard account at autoapplycv.in and autoapplycv.vercel.app.
