TITLE

HR Direct Outreach

SUMMARY
-------
Collects HR contact details from LinkedIn hiring posts and syncs them to your Cold Emails dashboard.

DESCRIPTION
-----------
Build your own HR outreach list from LinkedIn hiring posts.

What it does
- When you browse LinkedIn hiring search results, HR Direct Outreach collects HR contacts mentioned in the posts: name, job title, company, email, phone, and LinkedIn URL.
- Collected contacts are shown live with a contact counter, and can be exported to CSV.
- Syncs everything to your Cold Emails dashboard on autoapplycv.in so you can run outreach campaigns.

How it works
1. Open the HR Direct Outreach popup and enter a search keyword (e.g. "we are hiring").
2. Press Start Collecting — the extension opens LinkedIn hiring search results and scans posts.
3. Review collected contacts, export to CSV, or open the dashboard to run your campaign.

Features
- Keyword-based collection from LinkedIn hiring posts
- Collects name, title, company, email, phone, LinkedIn URL
- Pause / resume / clear with a live contact counter
- One-click CSV export
- Syncs to your Cold Emails dashboard

Important
- Only collect contact details from posts you are authorised to use for outreach.
- Use collected data responsibly and in line with applicable privacy laws.
- Data is stored in your own account; see the privacy policy at https://autoapplycv.in/privacy-policy

SINGLE PURPOSE DESCRIPTION
--------------------------
Collects HR contact details (name, title, company, email, phone) from LinkedIn hiring posts the user views, so the user can build their own outreach list, and syncs them to the user's own Cold Emails dashboard.

PERMISSION JUSTIFICATIONS
-------------------------
storage:
Stores collected contacts and collection state locally so the user can pause and resume collection and keep settings between sessions.

tabs:
Opens and focuses the LinkedIn tab used for collection and checks its URL to confirm it is a LinkedIn hiring search page.

scripting:
Injects the collection content script and panel into LinkedIn hiring search result pages.

activeTab:
Grants temporary access to the current LinkedIn tab when the user starts collection.

notifications:
Shows notifications when collection milestones are reached so the user knows progress without watching.

HOST PERMISSION JUSTIFICATION
