## 🚀 How to Load and Run the Unified Extension

1. Open Chrome and navigate to `chrome://extensions/`.
2. Turn on **Developer mode** (top right toggle).
3. Click **Load unpacked**.
4. Select the directory:
   `E:\Autoapply\CareerPilotLinkedInExtension\dist`
5. Pin the **AutoApply CV Suite** extension icon to your toolbar.
