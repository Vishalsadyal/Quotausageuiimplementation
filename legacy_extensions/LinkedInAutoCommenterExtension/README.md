# ⚡ LinkedIn Fast Auto Commenter (Personal Use)

A lightweight, high-speed Chrome extension to automatically comment on LinkedIn posts with your custom message or portfolio link (`https://parveen-portfolio-xi.vercel.app/`).

---

## 🚀 Key Features

- 🎯 **Direct User Input**: Type any custom comment, pitch, or portfolio link you want.
- ⚡ **Zero Bloat / No AI Dependencies**: Pure, direct DOM automation built for maximum speed and reliability.
- 🔗 **Built-in Quick Presets**:
  - `🔗 Portfolio Pitch`: `"Hi! I am actively looking for new opportunities. Feel free to check out my portfolio & recent work: https://parveen-portfolio-xi.vercel.app/"`
  - `⚡ Short Connect`: `"Great post! I'm currently exploring new opportunities. Check out my work: https://parveen-portfolio-xi.vercel.app/"`
- ❤️ **Auto-Like Feature**: Automatically likes each post before commenting (can be toggled on/off).
- 📜 **Continuous Feed Scrolling**: Auto-scrolls through your feed or search results.
- 🛡️ **Anti-Duplicate & Safety Protection**: Tracks commented post IDs so it never comments on the same post twice. Adjustable delay (seconds) with random jitter to stay safe.
- 🎛️ **Dual Control Interface**:
  1. **Floating On-Screen Overlay Widget** directly on LinkedIn pages (draggable, minimizable, live activity logs).
  2. **Extension Toolbar Popup** for quick configuration and stats.

---

## 📦 How to Install (Load Unpacked in Chrome)

1. Open Chrome (or Edge / Brave / Arc) and navigate to `chrome://extensions/`
2. Enable **Developer mode** (toggle in the top-right corner).
3. Click **Load unpacked** in the top-left corner.
4. Select the folder:
   ```
   E:\Autoapply\LinkedInAutoCommenterExtension
   ```
5. Pin the extension to your browser toolbar!

---

## 💻 How to Use

1. Open **[LinkedIn](https://www.linkedin.com/feed/)** or any search results page (e.g., `https://www.linkedin.com/search/results/content/?keywords=we%20are%20hiring`).
2. You will see the sleek floating **⚡ Auto Commenter** widget at the bottom right corner of the page (or open the extension popup).
3. Enter or modify your comment/portfolio message.
4. Set your preferred **Delay (seconds)** (recommended 3-6s) and **Max Posts**.
5. Click **🚀 Start Commenting**.
6. The extension will automatically scroll to each post, like it (optional), open the comment box, type your custom message, submit the comment, and wait for the delay before moving to the next post!
